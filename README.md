# 黄金超隐

面向隐私保护与兼容性测试的设备信息模拟模块（LSPosed / Xposed）。

- 模块包名：`io.github.superhide.viptry`
- 运行环境：LSPosed（或兼容的 Xposed 框架）+ root
- 支持系统：Android 7.0 及以上（API 24+）

## 功能

- **设备信息模拟**：品牌、厂商、机型、设备名、product、board、硬件、序列号、系统指纹、
  Android 版本、SDK 版本、IMEI、SSAID、GAID 等字段，可在模块内逐项开关。
- **GPS 虚拟定位**：按应用白名单 / 黑名单生效，未被选中的应用不受影响。
- **虚拟相机 / 虚拟麦克风**：为指定应用替换为配置好的媒体源（需相应权益）。
- **广告相关**：开屏广告跳过、摇一摇广告禁用、广告条测试。
- **隐私保护**：剪贴板保护与固定文本、禁止截图、应用列表注入、安全模式。
- **效率相关**：桌面快捷方式、侧边栏快捷方式、模拟模板、数据备份与定时任务。
- **多用户 / 双开**：可分别为不同用户空间生成独立机器码与配置。

## 使用方法

1. 在 LSPosed 中启用本模块，并**重启作用域内的目标应用**（必要时重启手机）。
2. 打开「黄金超隐」App，在应用列表里勾选需要模拟的目标应用。
3. 按需配置各项字段、定位或虚拟媒体源；配置保存在设备本地。
4. 部分能力需要注册码 / 权益授权，未授权时对应开关不生效或置灰。

## 注意事项

- 只勾选自己确实需要模拟的应用，**不要**把系统核心进程（如 `android`、`com.android.phone`）
  加入作用域，避免系统异常。
- 模拟设置仅作用于被勾选的应用进程；卸载模块后配置不会自动恢复。
- 每次发版的说明见本仓库的 Releases 页面。
